# 可行性验证记录

测试系统：Windows 10 22H2（10.0.19045）。测试浏览器：Google Chrome 155.0.8059.85。

**结论：已在三屏混合缩放环境验证枚举、切换与高亮；前台激活仍可能被 Windows 拒绝。** 本页仅公布软件版本与测试结论，不公布测试机器的屏幕配置、运行时编号、真实会话数量或个人偏好。

| 场景 | 已观察结果 |
| --- | --- |
| 三屏混合缩放 | 受控样本有通过记录；重复测试也出现过前台激活失败，不能保证每次成功 |
| 单窗口超过 20 个标签 | 专用的 24 个虚构测试标签枚举与批量切换均通过 |
| 多个 Chrome 窗口 | 已验证跨窗口切换，不公布原有会话信息 |
| 最小化窗口 | 有恢复、激活和选择成功记录，Provider 行为仍可能导致遗漏 |
| 后台标签 | 已验证选择原本未选中的专用测试标签 |
| 折叠标签组 | 仅有小型受控样本；复杂、多标签或多个折叠组未充分验证 |

可访问清单不等于 Chrome 内部全部标签。`COMPLETENESS_UNKNOWN` 表示没有独立的真实总数；不能把成功遍历当成完整覆盖。

选择前后核验窗口身份、目标 UIA RuntimeId、唯一选中状态和前台状态。身份失效时拒绝按标题或旧位置猜测。`FOREGROUND_DENIED` 表示前台策略、弹窗或焦点竞争导致激活失败，不能凭单个返回值确定唯一原因。已选择标签后出现高亮失败仍会明确报告。

上述场景矩阵没有安装扩展、重启 Chrome、使用调试端口、修改启动参数或读写 Chrome 配置。完整矩阵尚未在无扩展的干净 profile 中独立复测。文档演示另在临时隔离 profile 中验证了三屏跨窗口切换与高亮，不能代替完整矩阵。

其他 Windows / Chrome 版本、管理员级 Chrome、安全桌面、虚拟桌面、隐身窗口、全屏/PWA 等环境仍未充分验证。三屏通过结论不代表通用兼容性。

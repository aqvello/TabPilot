TabPilot v0.2.1 Preview 使用说明

界面语言：简体中文 / English。
点击右上角“中文 / EN”或托盘的“Language / 语言”选择，立即生效并记住选择。

1. 双击 TabPilot.exe，第一次会出现标签搜索浮窗。
2. 输入网页标题搜索，点击结果或按 ↑↓、Enter 切换。
3. 默认全局快捷键是 Ctrl + Alt + 空格。
   如果已被其他程序占用，应用会自动尝试其他可用组合键。
   请看浮窗底部显示的实际快捷键，也可以点右上角“快捷键”修改。
4. Esc、右上角 ×、点击窗口外部，只会隐藏到托盘。
5. 想退出：右击任务栏右下角的 TabPilot 托盘图标，选择“退出 TabPilot”；
   或在浮窗中按 Ctrl+Q。
6. F5 刷新，Ctrl+1 全部，Ctrl+2 按屏幕，Ctrl+3 最近使用。
7. 拖住顶部标题移动浮窗。隐藏、再次呼出及重启程序都会记住最后的位置和屏幕。
   原屏幕不可用时，浮窗会移到附近的可用屏幕，避免出现在屏幕外。

“最近使用”只记录通过 TabPilot 成功切换过的标签。
本版本不读取所有后台标签的域名，第二行显示所属窗口。
部分折叠组可能无法完整读取；窗口激活也可能受 Windows 的前台限制影响。
失败时浮窗会提示具体情况，可点击“详情”。
界面数量表示“读取到”的标签；折叠组、权限或超时可能导致遗漏。
已确认切换后，你转去操作别的窗口时，浮窗不会因为高亮期间焦点变化而抢回来。

无需 Chrome 扩展，不用重启 Chrome。
不改 Chrome 启动参数或配置，不使用远程调试端口。

要求：Windows 10 1703+ x64，.NET Framework 4.8。
请保留 TabPilot.exe.config。
自己的快捷键、浮窗位置、最近使用和诊断保存在同目录 data 文件夹。
程序目录不可写时，自动使用当前用户的 %LOCALAPPDATA%\TabPilot。
实际数据目录可在“详情”中查看；迁移时会尝试读取已有设置。
设置保留 settings.json.bak 备份，主文件损坏时尝试恢复。
保存失败会提示尚未保存，并在后台重试。
没有设置开机自启；重启电脑后请再运行一次程序。
